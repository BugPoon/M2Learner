為什麼要學「續三角函數」？

在中四時，我們學過直角三角形的三角比與基本關係。但當角度變成和差（如 $\theta + 45^\circ$）或雙倍（如 $2\theta$）時，我們需要全新的代數工具來進行變形。 本單元引進的和差角公式與倍角公式，是整個 M2 課程中最核心的「代數變形工具」，它們將在未來的微積分（求導與不定積分法）中扮演靈魂角色。

第 1 題 / 精確值 和角與差角

利用 $75^\circ = 45^\circ + 30^\circ$ 及 $15^\circ = 45^\circ - 30^\circ$，求下列各項的精確值 (Exact Value)：
(a) $\sin 75^\circ$      (b) $\cos 15^\circ$      (c) $\tan 75^\circ$

老師點撥： 直接代入正弦與餘弦的和差角公式。
例如 $\sin(A+B) = \sin A\cos B + \cos A\sin B$，帶入 $A=45^\circ, B=30^\circ$。記住特殊角精確值：$\sin 45^\circ = \frac{\sqrt{2}}{2}$，$\cos 30^\circ = \frac{\sqrt{3}}{2}$ 等。

(a) $\sin 75^\circ$ 解答步驟：

$$\sin 75^\circ = \sin(45^\circ + 30^\circ) = \sin 45^\circ\cos 30^\circ + \cos 45^\circ\sin 30^\circ$$ $$= \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) + \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right) = \frac{\sqrt{6} + \sqrt{2}}{4}$$

(b) $\cos 15^\circ$ 解答步驟：

$$\cos 15^\circ = \cos(45^\circ - 30^\circ) = \cos 45^\circ\cos 30^\circ + \sin 45^\circ\sin 30^\circ$$ $$= \left(\frac{\sqrt{2}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) + \left(\frac{\sqrt{2}}{2}\right)\left(\frac{1}{2}\right) = \frac{\sqrt{6} + \sqrt{2}}{4}$$

註：由於 $\sin 75^\circ = \cos(90^\circ - 75^\circ) = \cos 15^\circ$，兩者答案相等是完全合理的！

(c) $\tan 75^\circ$ 解答步驟：

$$\tan 75^\circ = \tan(45^\circ + 30^\circ) = \frac{\tan 45^\circ + \tan 30^\circ}{1 - \tan 45^\circ\tan 30^\circ}$$ $$= \frac{1 + \frac{1}{\sqrt{3}}}{1 - 1 \cdot \frac{1}{\sqrt{3}}} = \frac{\sqrt{3} + 1}{\sqrt{3} - 1}$$

進行分母有理化：

$$\frac{(\sqrt{3} + 1)^2}{(\sqrt{3} - 1)(\sqrt{3} + 1)} = \frac{3 + 2\sqrt{3} + 1}{3 - 1} = \frac{4 + 2\sqrt{3}}{2} = 2 + \sqrt{3}$$
第 2 題 / 雙倍角 倍角公式

已知 $\theta$ 為銳角，且 $\sin \theta = \frac{4}{5}$。求下列各項的值：
(a) $\sin 2\theta$      (b) $\cos 2\theta$      (c) $\tan 2\theta$

老師點撥： 既然 $\theta$ 是銳角，我們可以畫出一個 3-4-5 的直角三角形。由 $\sin \theta = \frac{4}{5}$，得到 $\cos \theta = \frac{3}{5}$，$\tan \theta = \frac{4}{3}$。接下來直接代入倍角公式！

第一步：求出 $\cos \theta$ 和 $\tan \theta$
因為 $\theta$ 是銳角且 $\sin\theta = \frac{4}{5}$，利用 $\cos^2\theta + \sin^2\theta = 1$：
$$\cos\theta = \sqrt{1 - \left(\frac{4}{5}\right)^2} = \frac{3}{5}$$
$$\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{4/5}{3/5} = \frac{4}{3}$$

第二步：計算各項

(a) $\sin 2\theta$：
$$\sin 2\theta = 2\sin\theta\cos\theta = 2 \left(\frac{4}{5}\right)\left(\frac{3}{5}\right) = \frac{24}{25}$$

(b) $\cos 2\theta$（三種公式皆可，這裡選純餘弦版）：
$$\cos 2\theta = 2\cos^2\theta - 1 = 2\left(\frac{3}{5}\right)^2 - 1 = 2\left(\frac{9}{25}\right) - 1 = \frac{18}{25} - \frac{25}{25} = -\frac{7}{25}$$

(c) $\tan 2\theta$：
$$\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta} = \frac{2\left(\frac{4}{3}\right)}{1 - \left(\frac{4}{3}\right)^2} = \frac{\frac{8}{3}}{1 - \frac{16}{9}} = \frac{\frac{8}{3}}{-\frac{7}{9}} = \frac{8}{3} \times \left(-\frac{9}{7}\right) = -\frac{24}{7}$$

第 3 題 / 恆等式證明 恆等化簡

證明下列恆等式：
$$\frac{\sin 2\theta}{1 + \cos 2\theta} = \tan \theta$$

老師點撥： 分子直接用正弦倍角公式展開為 $2\sin\theta\cos\theta$。對於分母，因為有 $+1$ 這個常數，我們選擇餘弦倍角公式中的 $\cos 2\theta = 2\cos^2\theta - 1$，利用其 $-1$ 來完美消去分母的 $+1$。

左方 (L.H.S.) 證明步驟：

$$\text{L.H.S.} = \frac{\sin 2\theta}{1 + \cos 2\theta}$$

將分子替換為 $2\sin\theta\cos\theta$，分母的 $\cos 2\theta$ 替換為 $2\cos^2\theta - 1$：

$$= \frac{2\sin\theta\cos\theta}{1 + (2\cos^2\theta - 1)}$$ $$= \frac{2\sin\theta\cos\theta}{2\cos^2\theta}$$

約去分子與分母中的公因式 $2\cos\theta$：

$$= \frac{\sin\theta}{\cos\theta}$$ $$= \tan\theta = \text{R.H.S.}$$ $$\because \text{L.H.S.} = \text{R.H.S.} \quad \therefore \text{該恆等式成立。} \quad \blacksquare$$
第 4 題 / 逆向套用 餘弦差角

不使用計算機，化簡並求出下列算式的精確值：
$$\cos 70^\circ \cos 10^\circ + \sin 70^\circ \sin 10^\circ$$

老師點撥： 逆向觀察公式！這道題的結構正是 $\cos A\cos B + \sin A\sin B$。這代表它等於一個單一的餘弦差角公式。試試把它合併起來。

解答步驟：

根據餘弦差角公式：$$\cos(A-B) = \cos A\cos B + \sin A\sin B$$

令 $A = 70^\circ$，$B = 10^\circ$，代入得：

$$\cos 70^\circ \cos 10^\circ + \sin 70^\circ \sin 10^\circ = \cos(70^\circ - 10^\circ)$$ $$= \cos 60^\circ$$

因為 $60^\circ$ 是特殊角，其餘弦精確值為：

$$= \frac{1}{2}$$
第 5 題 / 複合差角 恆等式證明

證明恆等式：
$$\frac{\cos(A-B) - \cos(A+B)}{\sin(A-B) + \sin(A+B)} = \tan B$$

老師點撥： 分子和分母分別用和角與差角公式全部展開。注意分子中間是「減號」，展開時記得把第二項括號起來，防止漏掉分配負號！展開後同類項會自然抵消。

證明步驟：

我們先展開分子部分：

$$\cos(A-B) - \cos(A+B) = (\cos A\cos B + \sin A\sin B) - (\cos A\cos B - \sin A\sin B)$$ $$= \cos A\cos B + \sin A\sin B - \cos A\cos B + \sin A\sin B = 2\sin A\sin B$$

接著展開分母部分：

$$\sin(A-B) + \sin(A+B) = (\sin A\cos B - \cos A\sin B) + (\sin A\cos B + \cos A\sin B)$$ $$= 2\sin A\cos B$$

將分子分母組合回原式（左方）：

$$\text{L.H.S.} = \frac{2\sin A\sin B}{2\sin A\cos B}$$

約去分子與分母的公因式 $2\sin A$：

$$= \frac{\sin B}{\cos B} = \tan B = \text{R.H.S.}$$ $$\because \text{L.H.S.} = \text{R.H.S.} \quad \therefore \text{該恆等式成立。} \quad \blacksquare$$
第 6 題 / R-Form 極值 輔助角應用

(a) 將 $5\sin \theta - 12\cos \theta$ 寫成 $R\sin(\theta - \alpha)$ 的形式，其中 $R > 0$ 且 $\alpha$ 為銳角（精確至最接近的 $0.1^\circ$）。
(b) 由此，求 $5\sin \theta - 12\cos \theta + 7$ 的最大值與最小值。

老師點撥： (a) 這裡 $a=5$, $b=12$，計算斜邊 $R = \sqrt{5^2 + 12^2}$，並用 $\tan\alpha = \frac{12}{5}$ 求出輔助角。(b) 合併成 $R\sin(\theta - \alpha) + 7$ 後，正弦函數本身的值域為 $-1 \le \sin(\text{任何角}) \le 1$，直接乘以 $R$ 後加 $7$ 即可。

(a) 解答步驟：

首先計算斜邊 $R$ 的值：

$$R = \sqrt{5^2 + (-12)^2} = \sqrt{25 + 144} = \sqrt{169} = 13$$

計算輔助銳角 $\alpha$：

$$\tan \alpha = \frac{12}{5} \implies \alpha = \tan^{-1}(2.4) \approx 67.38^\circ \approx 67.4^\circ$$

因此，原式寫為：

$$5\sin\theta - 12\cos\theta = 13\sin(\theta - 67.4^\circ)$$

(b) 解答步驟：

因為對於任意角度 $\theta$，正弦函數的值域為：

$$-1 \le \sin(\theta - 67.4^\circ) \le 1$$

兩邊同乘以 $13$ 得到波幅範圍：

$$-13 \le 13\sin(\theta - 67.4^\circ) \le 13$$

同加上常數 $7$ 以進行整體縱向平移：

$$-13 + 7 \le 13\sin(\theta - 67.4^\circ) + 7 \le 13 + 7$$ $$-6 \le 5\sin\theta - 12\cos\theta + 7 \le 20$$

所以，最大值為 $20$，最小值為 $-6$。

第 7 題 / 雙角求和 正切和角

已知 $\tan A = \frac{1}{2}$ 且 $\tan B = \frac{1}{3}$，其中 $A$ 和 $B$ 皆為銳角。
證明：$$A + B = 45^\circ$$

老師點撥： 既然題目要我們證明角度之和為 $45^\circ$，我們可以用「正切和角公式」算出 $\tan(A+B)$ 的數值。如果算出其值正好為 $1$，且由於 $A,B$ 均為銳角，就可以鎖定 $A+B = 45^\circ$！

證明步驟：

套用正切和角公式：

$$\tan(A+B) = \frac{\tan A + \tan B}{1 - \tan A\tan B}$$

將已知數值代入：

$$\tan(A+B) = \frac{\frac{1}{2} + \frac{1}{3}}{1 - \left(\frac{1}{2}\right)\left(\frac{1}{3}\right)} = \frac{\frac{5}{6}}{1 - \frac{1}{6}} = \frac{\frac{5}{6}}{\frac{5}{6}} = 1$$

判定角度範圍：

因為 $A$ 和 $B$ 皆為銳角，所以：

$$0^\circ < A < 90^\circ \quad \text{且} \quad 0^\circ < B < 90^\circ$$ $$\implies 0^\circ < A+B < 180^\circ$$

在這個範圍內，正切值等於 $1$ 的角度只有一個：

$$A+B = 45^\circ \quad \blacksquare$$
第 8 題 / 三角方程 倍角方程

在區間 $0 \le x < 2\pi$ 內，解方程：
$$\sin 2x - \sin x = 0$$
(請以弧度 $\text{rad}$ 表示答案)

老師點撥： ⚠️千萬不要兩邊同時除以 $\sin x$！先用正弦倍角公式將 $\sin 2x$ 展開為 $2\sin x\cos x$，然後提取公因式 $\sin x$，寫成兩項相乘為 $0$ 的乘積式，再分開解兩個簡單三角方程。

解答步驟：

$$\sin 2x - \sin x = 0$$

利用倍角公式：

$$2\sin x\cos x - \sin x = 0$$

提取公因式 $\sin x$：

$$\sin x (2\cos x - 1) = 0$$

這代表我們有兩個可能分支：

分支一：$\sin x = 0$
在區間 $0 \le x < 2\pi$ 中：
$$x = 0 \quad \text{或} \quad x = \pi$$

分支二：$2\cos x - 1 = 0 \implies \cos x = \frac{1}{2}$
在餘弦為正的第一和第四象限，其對應在 $0 \le x < 2\pi$ 內的角為：
$$x = \frac{\pi}{3} \quad \text{或} \quad x = 2\pi - \frac{\pi}{3} = \frac{5\pi}{3}$$

綜合所有解：

$$x = 0, \; \frac{\pi}{3}, \; \pi, \; \frac{5\pi}{3}$$
第 9 題 / 結構代數證明 DSE 模擬題

(a) 利用 $\cos 3\theta = \cos(2\theta + \theta)$，證明：
$$\cos 3\theta = 4\cos^3 \theta - 3\cos \theta$$
(b) 利用 (a) 的結果，解方程：
$$8x^3 - 6x - 1 = 0 \quad (\text{設 } x = \cos\theta, 0 \le \theta \le \pi)$$

老師點撥： (a) 把 $2\theta + \theta$ 帶入餘弦和角公式展開，再把所有的 $\sin 2\theta$, $\cos 2\theta$ 全部用倍角公式替換，最後利用 $\sin^2\theta = 1 - \cos^2\theta$ 轉化為只含 $\cos$ 的多項式。(b) 觀察方程 $8x^3 - 6x - 1 = 0$，如果我們兩邊同除以 $2$，會得到 $4x^3 - 3x = \frac{1}{2}$，這和 (a) 推導出來的 $\cos 3\theta$ 形式一模一樣！

(a) 證明步驟：

$$\cos 3\theta = \cos(2\theta + \theta) = \cos 2\theta\cos\theta - \sin 2\theta\sin\theta$$

將 $\cos 2\theta$ 代入 $2\cos^2\theta - 1$，將 $\sin 2\theta$ 代入 $2\sin\theta\cos\theta$：

$$= (2\cos^2\theta - 1)\cos\theta - (2\sin\theta\cos\theta)\sin\theta$$ $$= 2\cos^3\theta - \cos\theta - 2\sin^2\theta\cos\theta$$

將 $\sin^2\theta$ 替換為 $(1 - \cos^2\theta)$：

$$= 2\cos^3\theta - \cos\theta - 2(1 - \cos^2\theta)\cos\theta$$ $$= 2\cos^3\theta - \cos\theta - 2\cos\theta + 2\cos^3\theta$$ $$= 4\cos^3\theta - 3\cos\theta \quad \blacksquare$$

(b) 解答步驟：

給予方程：$8x^3 - 6x - 1 = 0 \implies 8x^3 - 6x = 1$

同除以 $2$ 得：

$$4x^3 - 3x = \frac{1}{2}$$

設 $x = \cos\theta$，代入得：

$$4\cos^3\theta - 3\cos\theta = \frac{1}{2}$$

根據 (a) 的結論，這就是三倍角公式：

$$\cos 3\theta = \frac{1}{2}$$

由於 $0 \le \theta \le \pi$，則 $3\theta$ 的範圍為 $0 \le 3\theta \le 3\pi$。

在此區間內，餘弦值等於 $\frac{1}{2}$ 的角度有：

$$3\theta = \frac{\pi}{3}, \; \frac{5\pi}{3}, \; \frac{7\pi}{3}$$ $$\implies \theta = \frac{\pi}{9}, \; \frac{5\pi}{9}, \; \frac{7\pi}{9}$$

由於 $x = \cos\theta$，所以方程的三個實根為：

$$x = \cos\frac{\pi}{9}, \; \cos\frac{5\pi}{9}, \; \cos\frac{7\pi}{9}$$
第 10 題 / 三角形幾何與代數 正切恆等式

設 $A$、$B$、$C$ 為三角形 $ABC$ 的三個內角。
(a) 證明：$\tan(A+B) = -\tan C$
(b) 由此證明：$\tan A + \tan B + \tan C = \tan A \tan B \tan C$

老師點撥： (a) 三角形內角和為 $180^\circ$，即 $A+B+C = 180^\circ \implies A+B = 180^\circ - C$。利用誘導公式 $\tan(180^\circ - \theta) = -\tan\theta$ 即可證明。(b) 將 (a) 證明出來的等式左邊用「正切和角公式」展開，然後兩邊去分母，把項移一移，就會神奇地湊出這條非常漂亮的對稱式！

(a) 證明步驟：

$\because A, B, C$ 為 $\triangle ABC$ 的內角，$\therefore A+B+C = 180^\circ \implies A+B = 180^\circ - C$

$$\text{L.H.S.} = \tan(A+B) = \tan(180^\circ - C)$$

利用正切誘導公式，由於第二象限的正切值為負：

$$= -\tan C = \text{R.H.S.} \quad \blacksquare$$

(b) 證明步驟：

由 (a) 可知：$$\tan(A+B) = -\tan C$$

將左邊用正切和角公式展開：

$$\frac{\tan A + \tan B}{1 - \tan A\tan B} = -\tan C$$

兩邊同乘以分母 $(1 - \tan A\tan B)$ 進行去分母：

$$\tan A + \tan B = -\tan C (1 - \tan A\tan B)$$

展開右邊的括號：

$$\tan A + \tan B = -\tan C + \tan A\tan B\tan C$$

將右邊的 $-\tan C$ 移項至左邊：

$$\tan A + \tan B + \tan C = \tan A \tan B \tan C \quad \blacksquare$$
第 11 題 / 輔助角綜合結構題 DSE Section B 難度

已知方程 $3\sin \theta + 4\cos \theta = k$ 有實數解。
(a) 求常數 $k$ 的取值範圍。
(b) 若 $k = 5$ 且 $0^\circ \le \theta \le 360^\circ$，求 $\theta$ 的值（精確至最接近的 $0.1^\circ$）。

老師點撥： (a) 對於左邊，利用輔助角公式將其合併成一個單一的 $R\sin(\theta + \alpha)$ 形式。由於正弦函數的最大、最小值分別為 $1$ 和 $-1$，方程有解代表 $k$ 必須落在這個合成波的值域內。(b) 當 $k=5$ 時，代入後等式變為 $5\sin(\theta + \alpha) = 5 \implies \sin(\theta + \alpha) = 1$。結合 $\theta$ 的範圍找出唯一的解。

(a) 解答步驟：

首先將左邊進行 $R$-form 合併：

$$R = \sqrt{3^2 + 4^2} = 5$$ $$\tan \alpha = \frac{4}{3} \implies \alpha = \tan^{-1}\left(\frac{4}{3}\right) \approx 53.13^\circ$$

因此方程等價於：

$$5\sin(\theta + 53.13^\circ) = k \implies \sin(\theta + 53.13^\circ) = \frac{k}{5}$$

由於對於任何實數 $\theta$，都有：

$$-1 \le \sin(\theta + 53.13^\circ) \le 1$$

所以，方程要有實數解，必須滿足：

$$-1 \le \frac{k}{5} \le 1 \implies -5 \le k \le 5$$

即常數 $k$ 的取值範圍為 $[-5, 5]$。

(b) 解答步驟：

當 $k = 5$ 時，方程為：

$$5\sin(\theta + 53.13^\circ) = 5 \implies \sin(\theta + 53.13^\circ) = 1$$

由於 $0^\circ \le \theta \le 360^\circ$，則角度範圍為：

$$53.13^\circ \le \theta + 53.13^\circ \le 413.13^\circ$$

在此區間內，正弦值等於 $1$ 的角度只有 $90^\circ$：

$$\theta + 53.13^\circ = 90^\circ$$ $$\theta = 90^\circ - 53.13^\circ = 36.87^\circ \approx 36.9^\circ$$

續三角函數「三大思想陷阱」 (點擊展開排雷)

錯誤行為：

很多同學看習慣了代數分配律 $x(y+z) = xy + xz$，便想當然耳地寫出 $\sin(A+B) = \sin A + \sin B$。

老師糾偏：

三角函數是一個「函數運算（Operator）」，絕對不是乘數！
正確代入： $\sin(A+B) = \sin A\cos B + \cos A\sin B$
隨意舉個反例：$\sin(30^\circ + 30^\circ) = \sin 60^\circ = \frac{\sqrt{3}}{2} \approx 0.866$。而 $\sin 30^\circ + \sin 30^\circ = 0.5 + 0.5 = 1$。兩者顯然不相等！

錯誤行為：

展開或化簡如 $(\sin 2\theta)^2$ 或 $(2\sin\theta)^2$ 的時候，經常漏掉對前方常數係數的平方計算。

老師糾偏：

根據指數律，$(ab)^n = a^n b^n$。所以：
$(2\sin\theta)^2 = 2^2 \sin^2\theta = 4\sin^2\theta$
這是極其普遍且可惜的扣分細節，考場上一定要睜大眼睛看清楚！

錯誤行為：

解方程 $\sin 2x = \sin x$ 時，直接展開 $2\sin x\cos x = \sin x$，然後左右兩邊同除以 $\sin x$ 得到 $2\cos x = 1$。

老師糾偏：

⚠️ 這是大忌！除非你已知該代數式絕對不為 $0$，否則絕對不能隨便同除！
左右約去 $\sin x$ 會直接導致你丟失了 $\sin x = 0$ 的所有解（如 $x = 0, \pi$）。
正確做法： 必須全部移項到等式左邊，利用「提取因式」來解方程：
$$2\sin x\cos x - \sin x = 0 \implies \sin x(2\cos x - 1) = 0$$
